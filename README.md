# Odd or Even Program

This repository contains a simple Python program to check if a number is odd or even.

## Features
- User input for the number
- Checks whether the input number is odd or even

## Usage
1. Run the program.
2. Enter an integer number when prompted.
3. The program will display whether the number is odd or even.

## Example
```
Enter a number: 5
The number 5 is Odd.
```
